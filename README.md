# aethelcode-core
Quantitative Finance And Data Science frameworks for high school students.
Official Platform: carrd.co
Phython Core Project: We use data to automate finance. Our main algorithm analyzes asset prices to detect market signals. If the stock increases more than four percent, the system automatically approves the trade. This clean code logic removes human mistakes and allows high frequency trading system to scan thousands of market numbers per second without any delay.
Portfolio Risk Analyzer: Our secondary algorithm evaluates asset stability. The software tracks market volatility. If the index is lower then five parcent, the computer executes the trade. This data system shields capital distribution.
